# Gitam EPOCH 4.0 Website

A web application for Gitam University's EPOCH 4.0 tech fest — built with React, Firebase, and a set of interactive WebGL/Canvas backgrounds.

| Layer | Description | Key Modules |
|-------|-------------|-------------|

## God Nodes (most connected)

- **`Raxios`** (12 edges) — Axios wrapper, bridge between auth and API calls
- **`Epoch 4.0`** (12 edges) — central event concept linking docs, UI, and media
- **`checkAccess()`** (10 edges) — auth guard called across 5+ screens
- **`useDeviceType()`** (9 edges) — responsive hook shared across components

## Communities

- **Auth & Scanner Screens** — login, QR lottery, notification screens, payment scanner
- **UI Components & Landing** — backgrounds, header, hero, events, team, info
- **App Shell & Firebase** — routing, context providers, Firebase messaging
- **Interactive Components** — Peep characters, FAQ accordion, intro slides, popups

## Backgrounds

15 animated backgrounds built with canvas 2D, each in its own component:
`CommitGraph`, `StarField`, `Universe`, `CircuitLines`, `Constellation`, `PaperTexture`, `RunnerStars`, `OrbitRings`, `Streams`, `WarpTunnel`, `GridWarp`, `Hyperspace`, `Aurora`, `ParticleNetwork`

## Tech Stack

- **React** (CRA) with React Router
- **Firebase** (auth, messaging, FCM)
- **Axios** with interceptor-based token refresh (`Raxios`)
- **Tailwind CSS** with PostCSS
- **Framer Motion** for animations
